# Glossary

**Status:** Reference  

| Term | Definition |
|------|------------|
| **AIP** | Autoimmune Insight Platform; working name for this project |
| **Ablation** | Disabling evidence layers to test contribution to rankings |
| **Autoantigen** | Host molecule targeted by autoimmune responses (context-dependent curation) |
| **Candidate pair** | Pathogen molecule ↔ host molecule relationship under analysis |
| **Congruence policy** | Rules defining acceptable agreement between re-runs |
| **Context pack** | Versioned bundle of disease-associated research inputs |
| **Computational hypothesis** | Ranked, explained, limited AIP output—not a medical claim |
| **Curated epitope** | Epitope from experimental/public curated resources |
| **Decoy** | Negative-control sequence/set for calibration |
| **Disclaimer stamp** | Mandatory research-only metadata on exports |
| **Evidence layer** | Category of features (sequence, epitope, HLA, …) |
| **Explanation trace** | Machine-readable contribution records grounding narratives |
| **HLA/MHC context** | Computational binding/presentation annotations for selected alleles |
| **Manifest** | Reproducibility descriptor for a run |
| **Molecular mimicry** | Hypothesis that microbial and host molecular similarity can relate to autoimmunity |
| **Plugin** | Swap-in adapter implementing a port contract |
| **Predicted epitope** | Algorithm-generated epitope; not experimentally confirmed by AIP |
| **Provenance** | Record of data/tool/steps producing an artifact |
| **Rank** | Investigative priority under a scoring model |
| **Run** | Immutable analysis execution bound to pins |
| **Snapshot** | Immutable mirrored dataset version |
| **Stage** | Pipeline unit with typed I/O |
| **Strict reproducibility** | Exact-hash matching mode for deterministic stages |

Add terms via PR; avoid synonyms that blur ethics boundaries (e.g., do not alias hypothesis to “diagnosis”).
