## Welcome

AIP welcomes contributions that improve open, reproducible, explainable molecular mimicry research tooling—while respecting ethical and medical boundaries.

---

## Before you start

1. Read [vision.md](../00-governance/vision.md), [non-goals.md](../00-governance/non-goals.md), [ethics.md](../00-governance/ethics.md).  
2. Search existing issues/ADRs.  
3. For large changes, open a design issue first.  

---

## Ways to contribute

- Documentation clarity  
- Tests & fixtures  
- Connectors & schema validations  
- New scorers as plugins  
- Bug fixes  
- Context pack curation (with provenance)  

---

## What we will reject

- Diagnostic/clinical decision features  
- PHI integrations without approved ADR  
- Unexplained black-box default rankers  
- Dual-use offensive capabilities  
- Fake citations / fabricated benchmarks  

---
