## Canonical disclaimer (full)

**AIP (Autoimmune Insight Platform) is a research bioinformatics software project.**  
It is intended solely to support computational research and education related to molecular mimicry analysis using publicly available biological data.

**AIP does not provide medical advice, diagnosis, prognosis, treatment recommendations, or clinical decision support.**  
Outputs generated by AIP—including similarity scores, epitope analyses, HLA-related computational contexts, rankings, visualizations, and natural-language summaries—are **computational hypotheses and methodological artifacts only**. They are **not** evidence of disease presence, disease risk, causation, or therapeutic action in any individual.

**No clinician–patient relationship is created** by using AIP.  
Users must not use AIP outputs to make personal health decisions. Always consult qualified healthcare professionals for medical concerns.

**Experimental and clinical validation are required** before any biological or medical interpretation beyond exploratory research discussion. AIP makes **no warranties** regarding accuracy, completeness, fitness for a particular purpose, or absence of errors in third-party data or tools.

By using AIP, you acknowledge these limitations and agree that maintainers, contributors, and affiliated organizations are **not liable** for decisions made based on software outputs.

> Research use only. AIP generates computational hypotheses, not medical advice or diagnoses. Results require scientific validation and must not guide personal health decisions.

## API disclaimer field

All API responses that return analysis results MUST include:

```json
{
  "disclaimer": {
    "code": "AIP_RESEARCH_ONLY",
    "version": "1.0",
    "text": "Research use only. Computational hypotheses, not medical advice or diagnosis."
  }
}
```

## Language blacklist (product-generated text)

Product-generated narratives must not use:

- diagnose / diagnosis / diagnostic for AIP outputs
- treat / treatment recommendation
- you have / patient has \<disease\>
- conclusively proves
- clinically confirmed (referring to AIP results)

Exceptions: quoting external clinical resources with clear attribution and without implying AIP confirmation.
